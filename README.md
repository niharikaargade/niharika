# Run the project

1. Open a terminal.
2. Go to the project folder:

```bash
cd /Users/farmx/niharika
```

3. Start a local server from the project root:

```bash
python3 -m http.server 4173
```

4. Open this URL in your browser:

```text
http://127.0.0.1:4173/
```

5. Keep the terminal running while you use the site.
6. Stop the server with `Ctrl+C`.

This project loads React, ReactDOM, Babel, and Google Fonts from CDNs, so your internet connection must be on while previewing it locally.
